# Level 3

Jalankan setiap jawaban secara terpisah dari direktori utama proyek:

```sh
node level-3/task-1/soal-1.js
node level-3/task-1/soal-2.js
node level-3/task-2/soal-1.js
node level-3/task-2/soal-2.js
node level-3/task-2/soal-3.js
node level-3/task-3/script.js
node level-3/task-4/script.js
node level-3/task-5/script.js
```

Ubah nilai `huruf` di `task-1/soal-2.js` menjadi `"b"` untuk melihat hasil konsonan.
